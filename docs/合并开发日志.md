### 关键环境事实(沿用,非可解约束)
- Windows / 控制台 GBK → 所有脚本 `sys.stdout.reconfigure("utf-8")`,命令前置 `PYTHONUTF8=1`。
- 8GB 显存(RTX 4060 Laptop)→ 强模型需分块/量化。
- CPU-only / Docker / 商用 license 红线**已全部解除**(全面开源,任意 license 可用,仅尽署名义务)。
- CREPE 必须 `pip install --no-deps crepe`(保 TF2.15 不被破坏)。
- LilyPond 用 `LILYPOND_EXE` 环境变量,**不放全局 PATH**(DLL 与 librosa/TF 冲突)。
- 多 venv 现实约束:`.venv`(CPU torch,扒谱/互转/渲染/GUI)/ `.venv-sep`(GPU,audio-separator)/ `.venv-neural`(cu124,DiffPitcher)/ `.venv-svc`(GPU,Seed-VC)互不干扰,不强行合一。
